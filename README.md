# fastprox

Exact proximal operators and projections with derivatives: a C++17 core
behind a plain-C API (`include/fastprox.h`), with Python bindings.
Design specification: [docs/spec.md](docs/spec.md). Planned work:
[ROADMAP.md](ROADMAP.md); finished changes: [CHANGELOG.md](CHANGELOG.md).
API reference: [docs/api.md](docs/api.md); benchmarks: [docs/benchmarks.md](docs/benchmarks.md).
